# JauntTrooper field questions

Public questionnaire and dated recovery summaries for the owner to answer while research continues. Open index.html or the GitHub Pages website. Original binaries, game art/audio, detailed private evidence, credentials and answer records are excluded.

Answers typed in the HTML stay as browser drafts until exported. The GitHub logging button opens a prepared issue in the private benjibrucker/mbbolt-firestorm-research repository. Sign in and press Submit new issue there to actually save. Edit or comment on that issue from another device. The public page cannot read private issues back into drafts. Import/export JSON carries drafts across devices.

This repository is intentionally separate from the private research and answer repository. Detailed evidence links require access. GitHub Pages is static; there is no token or automatic private API sync in the HTML.
