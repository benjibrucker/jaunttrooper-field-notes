Why we are asking · hint

What the recovered creature code checks

creature +21 means byte 21 in the record of the creature being examined. It does not name an enemy species. This path checks that bit 6 of byte 21 is off and bit 7 of byte 20 is on. Earlier noticing and random checks are only partly understood.

After a creature moves:
  if bit 6 in record byte 21 is OFF
     and bit 7 in record byte 20 is ON:
       this path can request the muttering cue

Earlier checks are omitted. This is a reading aid,
not executable recovered code.
